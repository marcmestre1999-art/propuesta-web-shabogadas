# Propuesta de rediseño web

Borrador de trabajo: **no es la web oficial** de S&H Abogadas, que está en
[shabogadas.com](https://shabogadas.com/).

Veintitrés versiones del mismo sitio (mismos textos y mismas páginas, distinto diseño).
Índice para compararlas: [`versiones.html`](./versiones.html).

Todas las páginas llevan `noindex`. Textos e imágenes pertenecen a S&H Abogadas.

Modo revisión (para dejar cambios propuestos sobre la propia web):
añade `?revision=1` a cualquier dirección.
